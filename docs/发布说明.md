# 发布说明

本项目按"需不需要处理校园网认证"分成两个版本，**代码同一套**，只是一个开关的差别。

---

## 版本 A · 联网版（`v1.1.0`）

**给谁用**：校园网需要门户认证（连上 WiFi 后还要在网页上登录账号）的环境。

**它会做什么**

```
定时唤醒
  → 点亮屏幕 + 关掉残留的开始菜单
  → 确保 WiFi：打开无线电 → 启用网卡 → 连接目标 SSID
  → 门户认证：账号密码(浏览器已保存) → 运营商 → 登录 → 确认弹窗
  → 关闭浏览器
  → 等 90 秒（让 GPU/网络稳定）
  → 启动 BetterGI → 点一条龙
  → 等结束 → 60 秒后睡眠
```

**安装**

```powershell
# 右键「以管理员身份运行」：
#   一键安装（右键以管理员身份运行）.cmd

# 或者命令行指定你自己的门户与 WiFi：
.\Install-BetterGI-OneDragon-Task.ps1 -Time 06:00 `
    -PortalUrl "http://<门户主机>:<端口>/<路径>/login.jsp" -WifiSsid "<你的WiFi名>"
```

**注意**

- 第一次用之前，先用浏览器手动登录一次并勾选「记住密码」，否则脚本无法自动填充。
- 门户地址和 WiFi 名必须改成你自己的，否则认证一定失败（日志会提示"PortalUrl 还没配置"）。

## 版本 B · 免联网版（`v1.1.0-lite`）

**给谁用**：网络开机即通的环境——有线上网、网络已自动认证、或者宿舍路由器已经处理了认证。

**它会做什么**

```
定时唤醒
  → 点亮屏幕 + 关掉残留的开始菜单
  → （完全不碰网络：不启动浏览器、不改 WiFi 设置、不等网络）
  → 启动 BetterGI → 点一条龙
  → 等结束 → 60 秒后睡眠
```

**安装**

```powershell
# 右键「以管理员身份运行」：
#   免联网安装（右键以管理员身份运行）.cmd

# 等价于：
.\Install-BetterGI-OneDragon-Task.ps1 -NoNetwork
```

**为什么单独做一个版本**

- 少一整条代码路径（浏览器自动化 + WLAN API），**出问题的面更小**；
- 不需要管理员去调 Wi-Fi、不会打开任何窗口；
- 如果你的网络本来就通，联网版每次也会先花 1~2 秒探测再跳过——免联网版连这个都省了。

---

## 两个版本的关系

| | 联网版 | 免联网版 |
|---|---|---|
| 唤醒 / 点亮屏幕 / 关浮层 | ✅ | ✅ |
| 连 WiFi、门户认证、关浏览器 | ✅ | ❌ 完全不执行 |
| BetterGI 一条龙 | ✅ | ✅ |
| 跑完睡眠 | ✅ | ✅ |
| 迟到保护 / 电池限制 | ✅ | ✅ |
| 需要的脚本 | 全部 | 全部（只是不调用认证脚本） |

**行为差异只来自任务参数**：

```
联网版   : -AutoCampusPortal:$true  (默认) -WaitNetworkSeconds 300
免联网版 : -AutoCampusPortal:$false        -WaitNetworkSeconds 0
```

---

## 已知限制（两个版本都适用）

- 依赖 **BetterGI 的界面文案**（`一条龙`、`任务列表`）。BetterGI 改版后可能需要调整锚点。
- 依赖 **Windows 的睡眠/唤醒行为**：只有睡眠（S3）能被唤醒定时器叫醒，**关机（S5）不行**。
- 如果睡眠前手动锁屏（Win+L），唤醒后任务会在锁屏界面跑，点击会落空——请把
  「如果你离开了，Windows 何时要求你重新登录」设为**从不**。
- 出现验证码/短信验证时无法自动处理：脚本会截图并退出，等人工介入。

## 变更摘要（v1.1.0）

- 新增：`-PortalUrl` / `-WifiSsid` 参数，可适配任意学校门户（不再内置某高校地址）
- 新增：免联网版安装入口（`-NoNetwork`）
- 新增：`docs/联网原理与适配.md` —— 原理、坑位、适配 checklist、排错速查
- 新增：`tools/Dump-PageUia.ps1` —— 一键抓取门户控件结构
- 改进：按钮点击改为 **UI Automation 元素定位**（不再依赖窗口比例坐标）
- 改进：联网判定改为 **curl + HTTPS**（避免劫持式认证的假阳性）
- 改进：WiFi 无线电用 **WLAN API** 打开（12 字节结构体，实测唯一可行）
- 改进：认证失败重试 5 轮；全败则 `exit 12` 不启动游戏
- 改进：迟到保护（`-MaxLatenessMinutes`，默认 120）
- 改进：启动延迟默认 90 秒（避免唤醒后立刻拉游戏触发显卡超时）

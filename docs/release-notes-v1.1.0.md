## 联网版 · 自动完成校园网门户认证

给**校园网需要网页认证**的环境（连上 WiFi 后还要登录门户）。

### 它会做什么

```
定时唤醒 → 点亮屏幕 → 关掉残留的开始菜单
  → 确保 WiFi：打开无线电 → 启用网卡 → 连接目标 SSID
  → 门户认证：账号密码（浏览器已保存）→ 运营商 → 登录 → 确认弹窗
  → 关闭浏览器
  → 等 90 秒（让 GPU / 网络稳定）
  → 启动 BetterGI → 点一条龙
  → 等结束 → 60 秒后睡眠
```

### 安装

```powershell
# 右键「以管理员身份运行」：
#   一键安装（右键以管理员身份运行）.cmd

# 或者指定你自己的门户与 WiFi：
.\Install-BetterGI-OneDragon-Task.ps1 -Time 06:00 `
    -PortalUrl "http://<门户主机>:<端口>/<路径>/login.jsp" -WifiSsid "<你的WiFi名>"
```

### 用之前必须做两件事

1. **先用浏览器手动登录一次**门户，并勾选「记住密码」（脚本不存密码，靠浏览器自动填充）；
2. **改掉默认的门户地址和 WiFi 名**（仓库里是占位符，不改一定失败）。

### 适配新门户

- 读 [docs/联网原理与适配.md](docs/联网原理与适配.md)（原理、坑位、checklist、排错速查）
- 用 `tools/Dump-PageUia.ps1` 抓一次你门户的控件结构，就知道该改哪个正则

### 行为要点

- 联网判定：`curl` + HTTPS（TCP 通 ≠ 能上网；校园网常是劫持式认证）
- 点击定位：UI Automation 元素矩形（比例坐标只做兜底）
- 认证失败重试 5 轮，全败则 `exit 12` **不启动游戏**（避免空转几十分钟）
- 迟到保护：超过预定时间 120 分钟就不补跑
- 仅接电源运行：`DisallowStartIfOnBatteries` + 脚本内二次检查
